# Result Archive

This directory contains the archived outputs from the completed experiment runs used in the paper.

The main archive lives in `results/circuit_depth/` and contains 52 result artifacts covering:

- the 6-qubit, 5000-sample primary batch
- the 10-qubit, 2500-sample supplementary batch
- both datasets used in the study

The files include circuit metrics, optimization comparisons, optimization-level sweeps, noisy-study aggregates, per-run noisy-study outputs, paired statistics, cross-validation results, and batch summaries.
