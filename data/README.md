# Data Notes

This directory contains the two CSV datasets used in the reported experiment runs.

- `IoT_Original_Distribution.csv`
- `UNSW_2018_IoT_Botnet_Final_10_Best.csv`

They are stored here so the repository can act as a self-contained experiment artifact. Because both files are large, this directory is configured for Git LFS.

Before making the repository public, check the redistribution terms for the original dataset sources and keep any required attribution with the release.
